# UPI Transaction Analysis Dashboard (Power BI)
  Project Overview
  
This Power BI dashboard provides an interactive analysis of UPI (Unified Payments Interface) transactions. It helps users explore transaction patterns, monitor payment trends, and gain insights into customer behavior through dynamic visualizations and filters.

# Key Features
-Interactive dashboard with multiple slicers and filters
-Transaction analysis by date
-Bank-wise transaction tracking
-City-wise transaction insights
-Device type analysis
-Gender-based transaction comparison
-Payment method analysis
-Merchant-wise transaction monitoring
-Purpose-wise transaction categorization
-Transaction type filtering and reporting

# Tools & Technologies
-Power BI Desktop
-Microsoft Excel / CSV Dataset
-Power Query
-DAX (Data Analysis Expressions)

# Dashboard Insights
-Analyze daily transaction volume and amounts
-Compare transaction activity across different banks
-Identify popular payment methods and transaction purposes
-Monitor transaction trends throughout the year
-Explore customer demographics and transaction behavior

# Dataset Fields
-Transaction Date
-Amount
-Bank Name (Sender)
-Bank Name (Receiver)
-City
-Device Type
-Gender
-Age Group
-Merchant Name
-Payment Method
-Purpose
-Transaction Type

#Business Value
This dashboard can help financial institutions, payment service providers, and analysts:

-Monitor transaction performance
-Understand customer payment behavior
-Identify transaction trends
-Support data-driven business decisions
